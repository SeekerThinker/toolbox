# Toolbox

从一件待办出发，记录、思考、专注、复盘，并在多端持续推进。

**在线使用：** https://seekerthinker.github.io/toolbox/

Toolbox 是一个轻量、开源、Local-first 的个人思考与执行系统。核心对象不是“工具”，而是一件具体要完成的事；思考方法、专注记录、计划、目标和长期校准都围绕同一条任务上下文组合使用。

## 核心原则

- **任务优先**：用户先想“我要把这件事做完”，而不是“我要用哪个工具”。
- **可选**：任何环节都不是前置条件；写几个字就可以直接开始番茄钟。
- **带上下文**：从任务进入任意方法时自动携带已有信息。
- **可组合**：拆解、决策、专注、复盘产生的信息继续属于同一个任务。
- **元认知不设门槛**：提示只负责帮助校准，不负责审批用户的流程。
- **Local-first**：不登录也能完整使用；账号只用于跨设备连续性。

最简单的路径始终可以是：

```text
写报告
→ 番茄钟
→ 完成
```

更复杂的任务则可以按需接入：

```text
捕获任务
   ↕
任务拆解 / 决策 / 原因探索 / 风险推演 / 学习
   ↕
番茄钟 / 深度工作
   ↓
任务历史
   ↓
复盘与长期校准
```

这些能力是可组合的，不是固定流程。

## 当前能力

### 任务

- 一行一件事，支持一次粘贴多行创建多个待办
- 可选记录完成标准、下一步、估时、计划时间、障碍、If-Then、优先级和复盘
- 打开任务即可直接开始番茄钟或深度工作
- 四象限只是任务集合的一种可选视图，不是独立工作流

### 思考与执行

目前保留 8 个高价值方法：

| 分类 | 方法 |
| --- | --- |
| 思维 | 任务拆解、Decision Journal、原因探索、事前风险推演、阶段复盘、解释与学习 |
| 专注 | 番茄钟、深度工作计时 |

方法库默认折叠，更推荐从具体任务中按需调用。

### 计划、目标与长期校准

年月周日不是四套重复任务列表，而是时间视野：记录当前周期最重要的方向、计划提醒和回顾调整，任务仍然只有一份。

目标是可选的长期对象，可以打卡、关联任务、查看关联任务完成情况和实际专注投入。

长期校准层会比较计划与实际，包括估时偏差、重复障碍、专注时间分布、Decision Journal 回看、周期事实和目标节奏。它只展示证据和趋势，不生成“生产力分数”。

## PWA 与快速捕获

Toolbox 可以作为 PWA 安装到支持的手机和桌面环境，并支持离线打开核心界面。

在支持 Web App shortcuts / Share Target 的平台上，可以：

- 从应用图标快捷进入“新建待办”
- 从其他 App 分享文字或链接到 Toolbox
- 分享内容只会带入待办草稿，不会自动创建，避免误操作

## 数据、账号与多端同步

默认数据保存在浏览器本地，并支持完整 JSON 导入 / 导出。

身份方式保持极简：**游客直接使用 + 邮箱验证码登录**。

- 不登录也能完整使用
- 没有密码、用户名或强制注册流程
- 首次邮箱验证码登录会自动创建账号
- 登录不会立即上传本机数据，用户仍需主动开启同步
- 同步覆盖任务、计划、目标、打卡、思考记录、专注历史、周期回顾、决策回看和偏好
- 本机与云端同时变化时不会静默覆盖，而是要求用户选择
- 云端使用 `revision` 做乐观并发控制
- 用户可以删除云端同步数据，也可以永久删除账号及云端数据
- 删除云端内容不会删除当前浏览器里的本地工作台

多端冲突规则集中在 `sync-policy.js`，生产同步代码与 CI 契约测试共用同一套决策：首次已有云端数据、后台发现远端更新、以及双端同时修改时，都不会静默覆盖本机内容。

生产 Supabase 后端已经部署：`toolbox_sync` 使用 Row Level Security 按 `user_id` 隔离，匿名用户不能读写同步数据；`toolbox_push` 负责并发安全写入；`delete-account` Edge Function 负责永久删除登录身份和云端数据。

公众邮箱 OTP 只有在正式邮件发送服务准备好后才会开放；未启用时普通用户仍然直接使用本机工作台。用户不会接触 Supabase key、回调地址或其他开发者配置。

## 技术结构

前端保持 **HTML + CSS + Vanilla JavaScript**，无 npm 构建流程。

```text
index.html                       # 待办优先的主界面
core.js                          # 存储、方法注册、任务上下文、导入导出
tasks.js                         # 捕获、待办、任务详情、历史与复盘
tools-thinking.js                # 思考方法
tools-focus.js                   # 番茄钟与深度工作
horizons.js                      # 日 / 周 / 月 / 年方向、目标与洞察
calibration.js                   # 长期校准
sync-policy.js                   # 多端同步冲突决策（生产与测试共用）
sync.js                          # 可选账号同步与具体云端 I/O
account-lifecycle.js             # 账号删除生命周期
pwa.js / capture.js              # PWA 安装与移动捕获
supabase/migrations/             # 数据库结构、RLS、并发控制
supabase/functions/delete-account/ # 永久删除账号 Edge Function
tests/                           # 产品模型、PWA、登录表面和同步契约测试
```

Supabase JS 只在需要账号 / 同步时加载。数据库和 Edge Function 使用标准 Supabase CLI 项目结构管理。

## 本地运行

```bash
python3 -m http.server 8080
```

需要验证本地 Supabase：

```bash
supabase start
supabase db reset
```

## 相关独立项目：Word 结构化思考与写作模板

Toolbox 会索引一个独立维护的 Word 写作项目：[`word-writing-templates`](https://github.com/SeekerThinker/word-writing-templates)。它把 Word 的标题层级和导航窗格当成结构化思考工具，让同一份文档从想法、大纲、正文一直成长到最终成稿。

在线选择器：**https://seekerthinker.github.io/toolbox/word-writing-templates/**

这里刻意保持边界：Toolbox 只负责发现与选择，不复制模板源码或二进制文件；模板生成、Release、Issues、兼容性记录和真实 Word 反馈都留在独立仓库。

## 当前方向

接下来的重点不是增加工具数量，而是继续减少一件事从“想到”到“完成”的摩擦：

1. 接通正式邮件发送服务并开放邮箱验证码登录
2. 验证手机捕获 → 云同步 → 电脑思考 / 专注 → 手机继续的完整多端链路
3. 让目标、任务和时间视野之间的关联更自然
4. 随真实样本积累，逐步增强估时和判断校准
5. 按真实需求接入日历、提醒事项和其他平台
